# Changelog

## 1.0.0 — first public release

### Structure
- Package in its own context ``LieSeries` ``, with usage messages for every public symbol. Internal tables are private.
- Lie series carry a stamp of the basis they belong to (`LieSeries[stamp, coefficients]`). Using a series from a previous call to `LieSeriesInitialize` gives the message `LieSeries::stale` instead of a silently wrong result. `LieSeriesQ` checks the stamp.
- The built-in Hall orders are kept in a registry and chosen with the new option `HallOrder` (`"Standard"`, `"Lyndon"`, `"Tall"`, `"Left"`, `"Right"`). `HallOrders[]` lists them. The legacy option `LessFunction` still accepts `Less`, `LyndonLess`, `LessTall`, `LessLeft`, `LessRight`.
- Paclet layout (`PacletInfo.wl`, `Kernel/`, `Tests/`, `Examples/`).

### New functions
- `HallBasisElements`, `HallDimension`, `NonZeroHallCoefficients`, `HallOrders`, `LieSeriesBasisInfo`.
- `LieSeriesMap` (from the later 2008 version of `LieSeries.m`): applies a function to each Hall coefficient of a Lie series.
- New Hall basis `HallOrder -> "PDegree"`, based on the P-degree (McLachlan & Murua 2019).
- Option `LieAlgebra -> "ClassicalMechanics"` of `LieSeriesInitialize`, to work in the Lie algebra of classical mechanics L(A,B)/I, I the ideal generated by [B,[B,[B,A]]], and the functions `ClassicalMechanicsBasisElements` and `ClassicalMechanicsCoefficients`.
- `ExpAd` (exp(ad_A) B) and `ZassenhausTerms`, previously only in the example notebook.
- Infix bracket `A ⋄ B` (`\[Diamond]`).
- Options `BCHLieSeries` and `SymmetricBCHLieSeries` to precompute the BCH series at initialization.
- `LieBracketFunction` is now also an option of `LieSeriesSubstitution`, `BCH` and `SymmetricBCH`.
- Lie series display can be copied and evaluated again as input in the notebook front end. A trailing … indicates nonzero terms above `$FormatMaxDegree`.
- Additional coefficient-wise operations: `Simplify`, `FullSimplify`, `Together`, `Factor`, `N`.

### Changed
- Removed the notation `{A, B}` for the bracket and its option `CurlyBracketNotation` (see Fixed). Use `LieBracket[A, B]` or `A ⋄ B`.
- `LieSeriesSubstitution` accepts the substitution rules in any order and evaluates only the Hall elements with nonzero coefficient.
- `HallCoefficients` always returns an ordinary list.
- Removed the experimental, unused order functions `LessLeft2` and `LessRight2`. User-defined order functions are no longer supported.

### Fixed
- `{A, B}` was turned into `[A, B]` for every two-element list of Lie series, including results of `Table`, `Array`, `Map`, etc.
- The Hall-set test evaluated the order function on the non-tree index 0 for generators (e.g. `LyndonLess[k, 0]`); the test is now short-circuited.
- `$BCHLieSeries` assigned a global variable `S`; several other loop variables (`m`, `lag1`, `lag2`, `ndif`, `iter`, `Xf`, `Yf`) leaked to the global context.
- Scalar multiplication also matched products of two Lie series, producing meaningless nested objects.
- `$SymmetricBCHLieSeries` only worked when the generators were named `"X"` and `"Y"`.
- `LieSeriesQ` referred to a nonexistent form of `LieSeries`.
- Duplicate definition of `LessRight2`; unused code (`checkfun`, `li`, `ri`, `si`) removed.
